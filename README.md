# Offline Habit & Daily Goal App

An Android-only, privacy-first personal habit and daily-goal application.

## Philosophy

> Local. Offline. Fast. Private. Simple.

The application stores and processes user data on-device and does not require an account, backend, cloud database, or internet connection for core functionality.

## Core Concepts

### Habits

Repeated behaviors tracked over time.

### Daily Goals

Specific outcomes the user wants to accomplish on a particular day.

### Today

A unified view of what matters today.

### History

An accurate record of what actually happened.

## Core Requirements

* Android only
* Completely offline
* Local persistent storage
* No mandatory account
* No backend
* No cloud dependency
* No advertising
* No telemetry
* Minimal permissions
* Battery-conscious
* Storage-efficient
* Memory-conscious
* Fast startup
* Reliable notifications
* User-controlled backup and restore
